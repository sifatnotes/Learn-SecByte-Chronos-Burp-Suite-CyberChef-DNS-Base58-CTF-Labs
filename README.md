# Learn SecByte Chronos, Burp Suite, CyberChef, DNS & Base58 CTF Labs

A hands-on collection of Learn SecByte cybersecurity and CTF labs covering Chronos injection and logic challenges, CyberChef web payloads, Base58 decoding, parameter ciphers, Burp Suite interception, virtual-host discovery, DNS reconnaissance, and hostname enumeration.

This repository is designed for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners developing practical web reconnaissance, encoding, interception, and application-security skills.

## Introduction

The collection focuses on web application testing, input analysis, encoding and decoding, HTTP interception, DNS-related reconnaissance, and virtual-host discovery in controlled CTF environments.

The supplied URLs explicitly reference **Chronos, CyberChef, Base58, Burp Suite, virtual hosts, DNS, hostnames, injection, logic testing, and parameter manipulation**. Difficulty ratings and CVE identifiers are not assumed unless specified by the supplied lab URLs.

## Learning Path

A practical progression through this collection is:

1. **Start with decoding fundamentals** using the Chronos Decode labs and Base58 Breakout.
2. **Explore CyberChef** to understand practical encoding and data-transformation workflows.
3. **Learn HTTP interception** with Burp Basics: Intercept to Exploit.
4. **Practice request analysis** using Chronos Intercept Decode.
5. **Study application parameters and logic** through Chronos Parameter Cipher and Chronos Logic Lab.
6. **Explore injection concepts** using Chronos Injection Lab in the authorized environment.
7. **Move into virtual-host and hostname discovery** with Virtual Host Hunt 2 and Chronos Hostname Hunt.
8. **Finish with DNS-focused reconnaissance** using Chronos DNS Forge.

## How to Use the Labs

1. Open a lab from the direct-link index.
2. Follow the lab's setup and authorization instructions.
3. Begin by examining the application's inputs, requests, or exposed information.
4. Identify encoded data, parameters, hostnames, and virtual hosts where relevant.
5. Use CyberChef or decoding techniques to analyze data.
6. Use Burp Suite only against the designated CTF target.
7. Test injection or application-logic concepts within the authorized environment.
8. Document requests, observations, findings, and lessons learned.
9. Reset and repeat the lab to improve your methodology.
